# 1.Yamato Protocol
[![Yamato Protocol](/images/blog/yamto_ogp.png)](https://app.yamato.fi/#/)
Yamato Protocol is an ETH over-collateralized stablecoin issuance protocol.  
It is a Dapp that allows you to borrow CJPY (Japanese yen-equivalent coin) using ETH as collateral.  
As of November 12, 2024, only CJPY can be borrowed, but other stablecoins (CUSD, CEUR, etc.) are planned to be issued sequentially.
#### URL
  - Yamato Protocol service site: [Yamato Protocol](https://app.yamato.fi/#/?lang=en)
  - Yamato Protocol official documentation: [Yamato Protocol Official Documentation](https://docs.yamato.fi/en?fallback=true)
#### Utility Token
[YMT (Yamato DAO Token)](https://docs.yamato.fi/en/ymt-yamato-dao-token): Not yet issued



# 2.Yabumi
[![Yabumi](/images/blog/yabumibanner.png)](https://www.yabumi.xyz/en#)
Yabumi is an innovative platform that enables sending and receiving tokens and NFTs using SNS accounts (such as Twitter and Discord) without needing to know the recipient's wallet address.  
You can send tokens and NFTs simply by specifying the recipient's SNS account.  
Recipients can also receive rewards while maintaining their privacy.
#### URL
  - Yabumi service site: [Yabumi](https://www.yabumi.xyz/en#)
  - Yabumi official documentation: [Yabumi Official Documentation](https://doc.yabumi.xyz/english?fallback=true)
#### Utility Token
[YBM (Yabumi DAO Token)](https://doc.yabumi.xyz/english/yabumi/ybm-yabumi-dao-token): Not yet issued



# 3.punodwoɔ
[![punodwoɔ](/images/blog/pnd-banner.png)](https://pnd.defigeek.xyz/)
punodwoɔ is a protocol that enables peer-to-peer lending and borrowing without intermediaries (administrators/third parties).  
Users can borrow base assets by depositing collateral assets into a pool, and earn interest by depositing base assets.  
You can use DFGC's governance token "[TXJP](/en/txjp)" as collateral to borrow ETH and other assets.
#### URL
  - punodwoɔ service site: [punodwoɔ](https://pnd.defigeek.xyz/)
  - punodwoɔ official documentation: [punodwoɔ Official Documentation](https://pnd-docs.defigeek.xyz/punodwo-dokyumento/english)

# 4.Yamawake
[![Yamawake](/images/blog/yamawake-banner.png)](https://yamawake.xyz/)
A Dapp that allows permissionless (without administrator approval) hosting and participation in token auctions.  
V1 supports bulk auction format, and various other auction formats are planned to be added in the future.  
Token IAOs for each DFGC product Dapp will be conducted using Yamawake.
#### URL
  - Yamawake service site: [Yamawake](https://yamawake.xyz/)
  - Yamawake official documentation: [Yamawake Official Documentation](https://docs.yamawake.xyz/english-3)
#### Utility Token
[YMWK (Yamawake DAO Token)](https://docs.yamawake.xyz/english-3/readme/ymwk-yamawake-dao-token): Not yet issued


# 5.Megumi
[![Megumi](/images/blog/megumi-banner.png)](https://megumi.defigeek.xyz/)
A general-purpose airdrop tool based on Merkle Trees. Airdrop organizers (Owners) create a recipient list (Merkle Tree) and deploy an airdrop contract via a Factory. Recipients (Claimers) can claim tokens using a Merkle Proof if their address is included in the list.  
An MGM token launch accompanied by an IAO is planned for the future.  

#### URL
  - Megumi service site: [Megumi](https://megumi.defigeek.xyz/)
  - Megumi official documentation: Megumi Official Documentation (under construction)
#### Utility Token
MGM (Megumi DAO Token): Not yet issued
